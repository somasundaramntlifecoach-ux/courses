முழுமையான மீள்பார்வை

🎯 Module 3 கற்றல் நோக்கங்கள்

இந்த Module-ஐ முடித்த பிறகு நீங்கள்,

  • கோபத்தின் போது ஆழ்ந்த மூச்சு ஏன் உதவுகிறது என்பதைப் புரிந்துகொள்வீர்கள்.
  • சரியான முறையில் ஆழ்ந்த மூச்சுப் பயிற்சியைச் செய்ய கற்றுக்கொள்வீர்கள்.
  • கோபம் அதிகரிக்கும் முன்பே மூச்சைப் பயன்படுத்தி உடலை அமைதிப்படுத்த முடியும்.
  • இந்தப் பயிற்சியை தினசரி வாழ்க்கையில் பயன்படுத்தத் தொடங்குவீர்கள்.
  • "Time-Out" என்றால் என்ன என்பதைப் புரிந்துகொள்வீர்கள்.
  • கோபம் அதிகரிக்கும் நேரத்தில் எப்போது இடைவெளி எடுக்க வேண்டும் என்பதை அறிந்துகொள்வீர்கள்.
  • Time-Out என்பது பிரச்சினையிலிருந்து ஓடுவது அல்ல என்பதைப் புரிந்துகொள்வீர்கள்.
  • சரியான முறையில் Time-Out எடுத்து, பின்னர் அமைதியாக உரையாடும் திறனை வளர்த்துக்கொள்வீர்கள்.
  • கோபத்தை அதிகரிப்பதில் எண்ணங்களின் பங்கு என்ன என்பதைப் புரிந்துகொள்வீர்கள்.
  • கோபத்தைத் தூண்டும் தன்னிச்சையான (Automatic) எண்ணங்களை அடையாளம் காண்பீர்கள்.
  • எதிர்மறை எண்ணங்களை சமநிலையான எண்ணங்களாக மாற்றக் கற்றுக்கொள்வீர்கள்.
  • கோபத்தின் போது அமைதியாக சிந்தித்து பதிலளிக்கும் திறனை வளர்த்துக்கொள்வீர்கள்.

📖 Module 3 சுருக்கம்

📌 பாடம் 3.1 — ஆழ்ந்த மூச்சுப் பயிற்சி

  • கோபத்தின் போது மூச்சு வேகமாக மாறும்.
  • ஆழ்ந்த மூச்சு உடலை அமைதிப்படுத்த உதவும்.
  • உடல் அமைதியானால், மனமும் மெதுவாக அமைதியாகும்.
  • கோபத்தின் உச்சநிலையைத் தவிர்க்க இது ஒரு பயனுள்ள முதல் படி.

📌 பாடம் 3.2 — Time-Out: சிறிய இடைவெளியின் சக்தி

  • Time-Out என்பது பிரச்சினையிலிருந்து ஓடுவது அல்ல.
  • அது கோபத்தின் தீவிரத்தை குறைக்கும் இடைவெளி.
  • இடைவெளிக்குப் பிறகு உரையாடலைத் தொடர வேண்டும்.
  • அமைதியான முடிவுகளுக்கு இது ஒரு சிறந்த நுட்பம்.

📌 பாடம் 3.3 — உங்கள் எண்ணங்களை மாற்றி கோபத்தை குறைப்பது

  • எண்ணங்கள் கோபத்தின் தீவிரத்தை அதிகரிக்கலாம் அல்லது குறைக்கலாம்.
  • உடனே முடிவுக்கு வராமல் முழு தகவலைப் புரிந்துகொள்ள முயற்சிக்க வேண்டும்.
  • சமநிலையான சிந்தனை அமைதியான நடத்தைக்கு வழிவகுக்கும்.
  • எண்ணங்களை மாற்றும் பயிற்சி தொடர்ந்து செய்யப்பட வேண்டும்.

🎯 Module 3 Quiz (Live)

1. கோபத்தின் போது பொதுவாக மூச்சு எப்படி இருக்கும்?

2. இந்தப் பாடத்தில் கூறப்பட்ட மூச்சுப் பயிற்சியின் முக்கிய நோக்கம் என்ன?

3. Time-Out-ன் முக்கிய நோக்கம் என்ன?

4. Time-Out எடுத்த பிறகு என்ன செய்ய வேண்டும்?

5. கீழ்க்கண்டவற்றில் எது கோபத்தின் தீவிரத்தை பாதிக்கிறது?

6. கோபத்தின் போது பயனுள்ள கேள்வி எது?

1. ஆழ்ந்த மூச்சுப் பயிற்சி, கோபத்தின் தீவிரத்தை குறைக்க உதவலாம்.

2. மூச்சுப் பயிற்சியை கோபம் வந்தபோது மட்டுமே செய்ய வேண்டும்.

3. Time-Out என்பது பலவீனத்தின் அடையாளம்.

4. Time-Out-க்குப் பிறகு உரையாடலைத் தொடர வேண்டும்.

5. ஒரே நிகழ்வை அனைவரும் ஒரே மாதிரி புரிந்துகொள்வார்கள்.

6. சமநிலையான சிந்தனை கோபத்தை குறைக்க உதவும்.
