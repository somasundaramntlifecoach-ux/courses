School management-உடன் coordinate செய்கிறோம்.

2. ஒரு Parent Situation

"என் குழந்தைக்கு ஏன் இவ்வளவு குறைவான mark போட்டிருக்கிறீர்கள்? அவன் நன்றாகத்தான்
படிக்கிறான். சரியாக paper correction செய்தீர்களா?"

Teacher அந்த message-ஐ படிக்கிறார்.

உடனே என்ன தோன்றலாம்?

"நான் சரியாகத்தான் correction செய்தேன்!"

"என்னையே question பண்றாங்களா?"

"அவங்க குழந்தை எப்படி எழுதினான் என்று தெரியுமா?"

உடனே reply type செய்ய ஆரம்பிக்கலாம்.

"Your child did not answer properly. Marks were given correctly."

Technically அது correct ஆக இருக்கலாம்.

4. முதல் Communication Tool

Acknowledge Before You Explain

Parent ஒரு concern சொல்லும்போது உடனே explanation கொடுப்பதற்கு முன்பு அவருடைய
concern-ஐ acknowledge செய்யுங்கள்.

உதாரணமாக:

"உங்கள் குழந்தையின் marks பற்றி நீங்கள் concern-ஆக இருப்பதை புரிந்துகொள்கிறேன்."

பிறகு:

"Paper-ஐ எப்படி evaluate செய்தோம் என்பதை நாம் சேர்ந்து பார்க்கலாம்."

இதன் அர்த்தம்:

Parent சொல்வது அனைத்தும் correct என்று accept செய்வது அல்ல.

அவருடைய concern-ஐ recognise செய்வது.

Acknowledge ≠ Agree

Acknowledge என்பது:

"நீங்கள் சொல்லும் concern-ஐ நான் கேட்டேன்."

என்ற message.

Assessment-ல் marks எப்படி வந்தது என்பதை நாம் சேர்ந்து பார்க்கலாம்."

7. Listen Before You Defend

சில நேரங்களில் parent complaint முழுமையாகக் கேட்பதற்கு முன்பே நாம் explanation
ஆரம்பித்துவிடலாம்.

Parent:

"Ma'am, என் child சொன்னது---"

Teacher:

"இல்லை, நடந்தது அப்படி இல்லை!"

Conversation ஆரம்பிப்பதற்குள் defence ஆரம்பமாகிவிட்டது.

அதற்கு பதிலாக:

Listen → Clarify → Respond

முதலில் முழுமையாக கேளுங்கள்.

பிறகு தேவையான clarification கேளுங்கள்.

பிறகு உங்கள் perspective-ஐ சொல்லுங்கள்.

என்று சொல்கிறார்.

உடனே:

அல்லது:

"நீங்கள் என்ன approach suggest பண்றீங்க? கொஞ்சம் explain பண்ண முடியுமா?"

என்று கேட்கலாம்.

Ask Before You Advise.

9. Clarifying Questions

Colleague ஒரு different opinion சொன்னால் உடனே counter argument கொடுப்பதற்கு
முன்பு ஒரு clarifying question கேளுங்கள்.

உதாரணமாக:

"அதை எப்படி implement பண்ணலாம் என்று நினைக்கிறீர்கள்?"

"இந்த approach-ல் உங்களுக்கு useful-ஆக தெரிந்தது என்ன?"

"இதைக் எந்த situation-ல் use பண்ணலாம்?"

ஒரு question conversation-ன் tone-ஐ மாற்றலாம்.

Ask for Help as Collaboration.

14. Difficult Conversation Formula

Parent அல்லது colleague-உடன் difficult conversation வந்தால் இந்த simple
structure-ஐ நினைவில் வைத்துக்கொள்ளுங்கள்:

A -- Acknowledge

அவருடைய concern-ஐ recognise செய்யுங்கள்.

L -- Listen

முழுமையாகக் கேளுங்கள்.

C -- Clarify

தேவையான கேள்விகளை கேளுங்கள்.

R -- Respond

Calm-ஆக உங்கள் perspective-ஐ சொல்லுங்கள்.

C -- Collaborate

Next step என்ன என்பதை சேர்ந்து முடிவு செய்யுங்கள்.

Acknowledge → Listen → Clarify → Respond → Collaborate

17. Professional Boundaries
