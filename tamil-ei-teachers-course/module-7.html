Classroom Discipline & Conflict Resolution-ல் Emotional Intelligence

மாணவரின் குணத்தைத் தாக்காமல் Behaviour-ஐ சரிசெய்வது

1. ஒரு Classroom Situation

அன்பான ஆசிரியர்களே,

நீங்கள் பாடம் நடத்திக்கொண்டிருக்கிறீர்கள்.

திடீரென்று இரண்டு மாணவர்கள் வாக்குவாதம் செய்ய ஆரம்பிக்கிறார்கள்.

சில seconds-ல் குரல் உயர்கிறது.

மற்ற மாணவர்கள் அனைவரும் அவர்களையே பார்க்க ஆரம்பிக்கிறார்கள்.

Lesson நின்றுவிட்டது.

Teacher-க்கும் irritation அதிகரிக்கிறது.

அந்த நேரத்தில்,

"இரண்டு பேரும் எப்ப பார்த்தாலும் இதே வேலைதான்!"

"உங்களுக்கு கொஞ்சமாவது discipline இருக்கா?"

என்று class முன்னால் திட்டத் தோன்றலாம்.

ஆனால் இங்கே இரண்டு பிரச்சனைகள் இருக்கின்றன.

ஒன்று:

Students-ன் conflict.

இரண்டாவது:

அந்த conflict-க்கு teacher கொடுக்கும் emotional response.

Teacher-ன் response situation-ஐ calm செய்யலாம்.

அல்லது இன்னும் escalate செய்யலாம்.

அதனால்தான் Classroom Discipline-ல் Emotional Intelligence மிகவும் முக்கியம்.

2. Discipline என்றால் என்ன?

Discipline-ன் நோக்கம்:

Student-ஐ அவமானப்படுத்துவது அல்ல.

Student-ஐ பயமுறுத்துவது அல்ல.

Teacher-ன் கோபத்தை வெளிப்படுத்துவது அல்ல.

நாம் address செய்ய வேண்டியது:

Behaviour.

அதையும் student-ன் dignity-ஐ பாதுகாத்து address செய்ய வேண்டும்.

EQ-Based Discipline:

Correct the Behaviour.\
Protect the Relationship.

Behaviour சரிசெய்யப்பட வேண்டும்.

ஆனால் relationship unnecessary-ஆக damage ஆகக்கூடாது.

3. Behaviour-ஐ Address செய்யுங்கள்; Character-ஐ அல்ல

ஒரு student நாம் explain செய்யும்போது தொடர்ந்து பேசுகிறார்.

Teacher:

"நீ எப்போதுமே இப்படித்தான்."

என்று சொல்கிறார்.

இங்கே நாம் ஒரு specific behaviour-ஐ address செய்யவில்லை.

Student-ன் character-ஐ describe செய்ய ஆரம்பித்துவிட்டோம்.

அதற்கு பதிலாக:

"நான் explain செய்யும்போது நீ பேசுவதால் class instructions miss ஆகிறது."

என்று சொல்லலாம்.

இங்கே focus:

Person அல்ல. Behaviour.

4. Behaviour vs Character

Character Statement:

"நீ ரொம்ப careless."

Behaviour-Focused Statement:

"இந்த வாரம் மூன்று முறை materials கொண்டு வராமல் இருந்திருக்கிறாய்."

Character Statement:

"நீ எப்போதும் disruptive."

Behaviour-Focused Statement:

"நான் instructions கொடுக்கும்போது நீ பேசுவதால் மற்றவர்கள் கவனம் சிதறுகிறது."

Character Statement:

"உனக்கு responsibility-யே கிடையாது."

Behaviour-Focused Statement:

"Assignment இன்று submit செய்யப்படவில்லை."

Behaviour-ஐ describe செய்யும்போது என்ன நடந்தது என்பதைப் பற்றி பேசுகிறோம்.

Character-ஐ attack செய்யும்போது student தன்னை defend செய்ய ஆரம்பிக்கலாம்.

5. ஒரு Simple Formula

Correction கொடுக்கும்போது இந்த structure-ஐ பயன்படுத்திப் பாருங்கள்:

Behaviour + Impact

Behaviour

என்ன நடந்தது?

Impact

அது class அல்லது learning-ஐ எப்படி பாதித்தது?

உதாரணம்:

"நான் instructions கொடுக்கும்போது நீ பேசினாய். அதனால் உனக்கும் அருகில்
இருப்பவர்களுக்கும் instructions miss ஆனது."

Specific.

Clear.

Behaviour-focused.

6. Public Correction vs Private Correction

ஒரு student தவறு செய்திருக்கிறார்.

Class முழுவதும் பார்த்துக்கொண்டிருக்கிறது.

அப்போது student-ஐ publicly confront செய்தால் அவர் behaviour-ஐ மட்டும் manage
செய்ய வேண்டியதில்லை.

Peers முன்னால் தனது image-ஐயும் protect செய்ய முயற்சி செய்யலாம்.

அதனால் defensiveness அதிகரிக்கலாம்.

Argument அதிகரிக்கலாம்.

Conflict escalate ஆகலாம்.

முடிந்தவரை:

Correct Privately.

எல்லா situation-லும் உடனடியாக private conversation possible ஆகாது.

Classroom safety அல்லது immediate disruption இருந்தால் teacher அந்த
behaviour-ஐ அந்த நேரத்திலேயே stop செய்ய வேண்டியிருக்கும்.

ஆனால் detailed discussion-ஐ appropriate private moment-க்கு மாற்றலாம்.

7. Real-Life Example

Class நடக்கும்போது இரண்டு students loudly argue செய்ய ஆரம்பிக்கிறார்கள்.

Teacher உடனே class முன்னால்:

"இரண்டு பேரும் என்ன problem?"

என்று நீண்ட argument-க்கு செல்லவில்லை.

முதலில் இருவரையும் calm-ஆக separate செய்கிறார்.

Lesson-ஐ continue செய்கிறார்.

அடுத்த break-ல் இருவருடனும் conflict-ஐ address செய்கிறார்.

இதனால்:

Classroom attention பாதுகாக்கப்படுகிறது.

Public humiliation குறைகிறது.

Conflict-ஐ calmer setting-ல் discuss செய்ய முடிகிறது.

First:

De-escalate.

Then:

Resolve.

8. Conflict நேரத்தில் முதலில் என்ன செய்ய வேண்டும்?

இரண்டு students argue செய்கிறார்கள்.

அந்த நேரத்தில்:

"யார் ஆரம்பித்தது?"

"நீ என்ன சொன்ன?"

"அவன் என்ன சொன்னான்?"

என்று முழு investigation-ஐ class நடுவில் ஆரம்பிக்க வேண்டியதில்லை.

முதலில்:

Conflict-ஐ stop செய்யுங்கள்.

Students-ஐ separate செய்யுங்கள்.

Class-ஐ stabilise செய்யுங்கள்.

பிறகு appropriate moment-ல் underlying issue-ஐ address செய்யுங்கள்.

Calm First. Solve Next.

9. Predictable Consequences

ஒரே behaviour.

Monday ஒரு consequence.

Tuesday வேறு consequence.

Wednesday teacher good mood என்பதால் consequence இல்லை.

Thursday teacher stress-ல் இருப்பதால் very strong consequence.

இப்படி இருந்தால் student-க்கு rule-ஐ விட teacher-ன் mood முக்கியமாகத் தோன்றலாம்.

EQ-based discipline-ல்:

Predictability matters.

Common issues-க்கு clear, fair, consistent response structure இருக்க
வேண்டும்.

இதனால் students:

"இந்த behaviour நடந்தால் என்ன response வரும்?"

என்று முன்கூட்டியே புரிந்துகொள்ள முடியும்.

10. Consequence கோபத்தில் உருவாகக்கூடாது

Student ஒரு mistake செய்கிறார்.

Teacher மிகவும் angry.

அந்த emotional peak-ல் consequence decide செய்தால் அது mood-based ஆகிவிடலாம்.

அதனால் Module 3-ல் பார்த்ததை நினைவில் கொள்ளுங்கள்:

Pause → Regulate → Respond

தேவைப்பட்டால்:

"இதற்கான next step என்ன என்பதை நான் class முடிந்த பிறகு சொல்கிறேன்."

என்று நேரம் எடுத்துக்கொள்ளலாம்.

Immediate emotional punishment-ஐ விட predictable response முக்கியம்.

11. "Always" மற்றும் "Never" Words

Correction-ல் நாம் அடிக்கடி பயன்படுத்தும் இரண்டு words:

Always

Never

"நீ எப்போதுமே இப்படித்தான்."

"நீ ஒருபோதும் கேட்கவே மாட்டாய்."

இவை current behaviour-ஐத் தாண்டி student-ன் முழு identity-யை judge செய்வது
போலத் தோன்றலாம்.

அதற்கு பதிலாக:

Current Behaviour + Current Impact

பற்றிப் பேசுங்கள்.

"இன்று நான் instructions கொடுத்த இரண்டு நேரங்களில் நீ பேசினாய்."

Specific.

Addressable.

12. Conflict-ல் Teacher-ன் Tone

Teacher correct message சொல்லலாம்.

ஆனால் tone aggressive-ஆக இருந்தால் conflict escalate ஆகலாம்.

அதனால் discipline conversation-ல்:

Voice volume.

Facial expression.

Body posture.

Words.

இவை அனைத்தும் முக்கியம்.

Module 3-ல் பார்த்தது போல:

கோபம் அதிகரிக்கும்போது voice raise செய்வதற்குப் பதிலாக lower voice
பயன்படுத்துவது ஒரு regulation tool.

Firm ≠ Loud.

Firm ஆக இருக்கலாம்.

Respectful-ஆகவும் இருக்கலாம்.

13. Kind + Firm

EQ-based discipline-ஐ ஒரு simple phrase-ல் நினைவில் வைத்துக்கொள்ளலாம்:

Kind and Firm

Kind:

Student-ன் dignity-ஐ respect செய்வது.

Firm:

Boundary-ஐ clear-ஆக maintain செய்வது.

உதாரணம்:

"நீ upset-ஆ இருக்கிறாய் என்பதை நான் புரிந்துகொள்கிறேன். ஆனால் class-ல் மற்றவரை
insult செய்வது acceptable இல்லை. இதைப் பிறகு தனியாகப் பேசலாம்."

Understanding இருக்கிறது.

Boundary-யும் இருக்கிறது.
